## Law

| form | units | standard |
|---|---|---|
| `A void ≐ A` | `A ≐ A` | a + 0 = a |

The empty page is a form. Writing nothing beside a form changes nothing.

## Plain

Zero is what you have when you have written nothing at all; adding nothing changes nothing.

## Derivation

none — adjoined. This is a fact of the medium, not an axiom: "A void" and "A" are the same inscription.

## Confirms

The additive identity 0, and the fact that it is *unique*: there is only one way to write nothing. It is **not** yet the number zero as an object you can point at — that arrives as a value, `(□) ≐ void`, at [[mult.hole-instance]]. In Laws of Form this is the unmarked state.
